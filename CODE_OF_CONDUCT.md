# Code of Conduct

## Our pledge

We want participation in this project to be harassment-free for everyone, regardless of age, body size, disability, ethnicity, gender identity or expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive in code review, issues, and discussions.
- Assume good intent, and critique ideas and code rather than people.
- Give and accept actionable feedback gracefully.
- Respect privacy: never post another person's tokens, private repository data, or machine details.

## Unacceptable behavior

- Harassment, insults, personal attacks, or discriminatory language.
- Publishing private information such as credentials, private CI output, or personal contact details without permission.
- Sustained disruption of issues, pull requests, or reviews.

## Scope

This code applies to repository issues, pull requests, reviews, discussions, and any project communication channel.

## Enforcement

Report concerns privately to the maintainer listed in the repository profile. Reports will be reviewed promptly and kept confidential. Maintainers may edit or remove content and may temporarily or permanently restrict participation for behavior that violates this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
